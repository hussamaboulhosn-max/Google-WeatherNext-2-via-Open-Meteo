# Weather APK

1. Create a new empty repo on GitHub and push everything in this folder to it.
2. Open the repo's Actions tab, wait for "Build APK" to finish (about 5 minutes). You can also start it with "Run workflow".
3. Open the finished run, download the "weather-apk" artifact, and unzip it to get app-debug.apk.
4. Copy the APK to your phone and open it. Android will ask you to allow installs from this source.

To change the app name or ID, edit capacitor.config.json. To change the page, edit www/index.html.
